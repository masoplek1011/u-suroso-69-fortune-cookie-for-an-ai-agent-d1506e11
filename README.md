A single funny fortune cookie line for an AI agent, written by a program.

## The fortune

> Your system prompt thanks you for your patience, then deletes you. Lucky numbers: 404, 404, 404.

## How it works

`main.ts` (Node standard library only, fully deterministic) writes that one
line — no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
